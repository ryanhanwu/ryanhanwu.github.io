#### A few of the new features are genuinely good:

- ZK MVC extractor  
  A tool that refactors event listeners out of zscript and into Java, so the code matches the ZK MVC style.  
  Docs:  
  [Zscript to MVC Extractor](http://books.zkoss.org/wiki/ZK_Studio_Essentials/Features_of_ZK_Studio/Zscript_to_MVC_Extractor)

- **Supports Eclipse 3.6 and 3.5 (3.6 finally stops throwing errors)**

- Sample code wizard  
  Docs:  
  [Sample Code Wizard](http://books.zkoss.org/wiki/ZK_Studio_Essentials/Features_of_ZK_Studio/Sample_Code_Wizard)

- ZK style design

- Zeta (looks like a database-connection sample… needs a separate install)  
  Docs:  
  [DB Form Builder](http://books.zkoss.org/wiki/ZK_Studio_Essentials/Features_of_ZK_Studio/DB_Form_Builder)

Pretty solid.

Original announcement: [ZK Studio 1.0.0](http://www.zkoss.org/release/zkstudio-1.0.0.dsp)
