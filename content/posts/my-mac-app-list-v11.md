Updated the software list. Anything marked with \* wants money before it is actually pleasant to use.

### Productivity

- [SizeUp](http://www.irradiatedsoftware.com/sizeup/): window management. Free to use. It pops a demo window, which is harmless.
- [Mou](http://mouapp.com/): Markdown editor with a live preview.
- [Dash](http://itunes.apple.com/us/app/dash-docs-snippets/id458034879?mt=12): quick snippets and doc lookup. After 2012 it keeps asking you to spend NT$300, and it will keep interrupting you until you do. Be careful.

### Browser

- Firefox
- Chrome
- [Chrome Canary](https://tools.google.com/dlpage/chromesxs): for web developers only. The future of Chrome, ahead of schedule. \*

### Storage

- [Dropbox](https://www.dropbox.com/home): the best cloud file storage.
- [SkyDrive](https://skydrive.live.com/): Microsoft cloud storage. Still using it because an earlier promo left me with 25 GB.
- [Google Drive](https://drive.google.com/start): Google cloud file storage. \*

### Development and editors

- [Sublime Text](http://www.sublimetext.com/): my favorite plain-text editor. Settings are in [this post](http://blog.flyworld.me/2012/03/my-sublime-text-2-on-windows-7-64bit.html).
- [SmartGit](http://www.syntevo.com/smartgit/index.html): the best Git client I have used so far. SourceTree has wrecked a repo of mine.
- [Evernote](http://evernote.com/): the notes app I actually use every day.
- [HTTP Client](http://ditchnet.org/httpclient/): a visual way to fire HTTP requests. \*
- Xcode: iOS development. \*

### Network and multimedia

- [Hao Zhao Pian](http://www.haozhaopian.com/): handy photo effects.
- [FireAlpaca](http://firealpaca.com/): a free image editor.
- [Skitch](http://skitch.com/): screenshots, with a basic pen for markup.
- [KKBox](http://tw.kkbox.com/): music everywhere, without filling the disk. Support Taiwanese software. Kaohsiung, oh yeah. \*
- [VLC Player](http://www.videolan.org/vlc/): the most universal video player I have found.
- [HandBrake](http://handbrake.fr/): video conversion with very few steps.
- [iGetter](http://www.igetter.net/index.html): a download manager that can resume. \*

### Terminal

- [Go2Shell](http://itunes.apple.com/us/app/go2shell/id445770608?mt=12): open Terminal in the current Finder folder.
- [iTerm2](http://www.iterm2.com/): a stronger Terminal. Autocomplete and split panes suit anyone who lives in the CLI. \*

### Social

- [TweetDeck](http://www.tweetdeck.com/): Twitter client. Useful when you are juggling accounts (I still have the jsdc.tw one).
- [Skype](http://www.skype.com): Microsoft killed MSN. This is what is left.
- [Line](http://line.naver.jp/): the chat app everyone is on right now. \*
