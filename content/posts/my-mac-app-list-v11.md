更新了一下軟體列表，請參考。有\*的是要付費才能好好使用的。

-   生產力軟體(Productivity)
    
-   [SizeUp](http://www.irradiatedsoftware.com/sizeup/)：多視窗管理，很方便 (免費使用，會跳Demo視窗，但不礙事)
    
-   [Mou](http://mouapp.com/)：Markdown 即時預覽編輯器
-   [Dash](http://itunes.apple.com/us/app/dash-docs-snippets/id458034879?mt=12)_：快速Snippets與文件查詢工具 (2012之後會一直叫你花NT300買不然就會一直干擾…請謹慎)_ 瀏覽器(Browser)
    
-   Firefox
    
-   Chrome
-   [Chrome Canary](https://tools.google.com/dlpage/chromesxs) : For Web Developer Only, power new future chrome\* 儲存(Storage)
    
-   [Dropbox](https://www.dropbox.com/home) : Best Cloud File Storage
    
-   [SkyDrive](https://skydrive.live.com/)：Microsoft Cloud File Storage 因為有之前活動獲得的25G，所以還是用一下。
-   [Google Drive](https://drive.google.com/start) : Google Cloud File Storage\* 開發與編輯器(Development & Editor)
    
-   [Sublime Text](http://www.sublimetext.com/)：我最愛的純文字編輯器，設定可以[參考這篇](http://blog.flyworld.me/2012/03/my-sublime-text-2-on-windows-7-64bit.html)
    
-   [SmartGit](http://www.syntevo.com/smartgit/index.html)：目前覺得最好用的Git Client (SourceTree把我repo搞爛過…)
-   [Evernote](http://evernote.com/) : 日常生活必備的筆記App
-   [HTTP Client](http://ditchnet.org/httpclient/)\* : 視覺模擬HTTP Request用
-   XCode：iOS Development\* 網路與多媒體(Network & Mutimedia)
    
-   [好照片](http://www.haozhaopian.com/)：方便的照片特效處理軟體
    
-   [FireAlpaca](http://firealpaca.com/) : 免費的圖像編輯軟體
-   [Skitch](http://skitch.com/)：螢幕截圖軟體，附上基本畫筆可以標記
-   [KKBox](http://tw.kkbox.com/)\* : 到處聽音樂，不用下載占空間 (支持台灣軟體發展！高雄Oh~Ya)
-   [VLC Player](http://www.videolan.org/vlc/) : 目前找到最通用的Video Player
-   [HandBrake](http://handbrake.fr/) : 步驟很簡單的影片轉檔軟體
-   [iGetter](http://www.igetter.net/index.html) : 續傳軟體\* 終端機相關(Terminal)
    
-   [Go2Shell](http://itunes.apple.com/us/app/go2shell/id445770608?mt=12)：可以直接在Finder上開啟該目錄的Terminal
    
-   [iTerm2](http://www.iterm2.com/)：加強版Terminal，自動完成/畫面切割對於CLI愛好者很適合\* 社交軟體(Social)
    
-   [TweetDeck](http://www.tweetdeck.com/)：Twitter Client, 管理多帳號的時候很方便(我還有jsdc.tw的帳號…)
    
-   [Skype](http://www.skype.com) : 微軟沒了MSN，只剩下他了
-   [Line](http://line.naver.jp/) : 目前最夯的即時通訊App\* 系統軟體
