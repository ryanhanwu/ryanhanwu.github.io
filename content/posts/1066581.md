---
title: "Wrapping Lines in Hlayout"
description: "Hlayout defaults to white-space: nowrap. Set white-space: normal on the child if you want the line to wrap."
publishDate: "2011-05-31T22:35:17.000Z"
tags: ["zk", "coding", "css", "layout", "frontend"]
---

```xml
<hlayout>
  <div class="mydiv" />
</hlayout>
```

Hlayout

Default:

```css
white-space: nowrap;
```

**Change it to:**

```css
.mydiv {
  white-space: normal;
}
```
